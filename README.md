## 🚀 Getting Started

### Prerequisites

- **Python 3.10+** installed ([download](https://www.python.org/downloads/))
- **Git** installed ([download](https://git-scm.com/))

### 1 · Clone the Repository

```bash
git clone https://github.com/<your-github-username>/Churn-Prediction-ML.git
cd Churn-Prediction-ML
```

### 2 · Create a Virtual Environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3 · Install Dependencies

```bash
pip install -r requirements.txt
```

### 4 · Train the Model *(first-time only)*

```bash
python train_model.py
```

This generates `churn_model.pkl` and `model_features.pkl`.

### 5 · Launch the Dashboard

```bash
streamlit run churn_dashboard.py
```

The app opens at **http://localhost:8502** — enjoy! 🎉

## 🤖 AI Assistant — How It Works

Type a question in the sidebar and click **Analyze**:

| Question Type | Example | Response |
|:---|:---|:---|
| 📝 Contract | *"Which contract has the highest churn?"* | Recommends 1-year upgrade offers for month-to-month customers |

| ❓ Other | *"What is the weather?"* | Politely redirects to supported topics |
