## ✨ Key Features

| Feature | Description |
|:---|:---|
| 🤖 **Random Forest Classifier** | Trained on 7,043 customer records — achieves **77% accuracy** with balanced class weighting |
| 📊 **Interactive Streamlit Dashboard** | Wide-layout, premium UI with real-time KPI cards, Plotly charts, and data tables |
| 🌗 **Light / Dark Mode Toggle** | Full theme system (35+ design tokens) with smooth CSS transitions — switch in one click |
| 🎛️ **Dynamic Filtering** | Adjustable risk threshold slider & contract-type filter update every chart and KPI live |
| 🧠 **AI Assistant** | Sidebar chatbot answers questions about contract risk & churn drivers using keyword matching |
| 📈 **ROC-AUC Curve** | Visual model evaluation with area-under-curve metric |
| 🏆 **Feature Importance** | Top 12 drivers ranked — actionable insight for business strategy |
| 📋 **At-Risk Customer Table** | Top 25 highest-probability churners with gradient-highlighted churn scores |
